# Web App

This folder is the planned frontend for MSF_DB.

## Purpose

The web app should give users a fast way to:

- Explore SQL shortcuts.
- Filter by database.
- Filter by category.
- Search shortcuts.
- Copy query text.
- Read explanations.
- See risk labels.
- Generate documentation from schema input.

## Intended UI Pieces

- SQL Shortcut Explorer
- Shortcut filter bar
- Search input
- Shortcut detail drawer or panel
- Copy query button
- Explain query action
- Risk badge
- DBDocs Gen input panel

## Notes

This folder is intentionally lightweight for now so the repository can be reorganized safely without breaking the existing legacy folders.
