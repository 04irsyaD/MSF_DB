# Examples

This folder contains sample inputs and outputs for MSF_DB features.

## Suggested Use

- Store sample SQL DDL inputs.
- Store generated Markdown documentation examples.
- Store database-specific demo payloads.
- Keep examples grouped by engine so the frontend can reference them easily.

## Suggested Layout

- `mysql/`
- `postgresql/`
- `sqlserver/`
- `oracle/`
- `mongodb/`
- `databricks/`
- `snowflake/`
