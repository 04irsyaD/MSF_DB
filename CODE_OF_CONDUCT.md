# Code of Conduct

## Our Pledge

We want this repository to be a welcoming and useful place for people who share database queries, documentation workflows, automation scripts, and application examples.

Everyone who participates in this project is expected to communicate respectfully, assume good intent, and help keep discussions focused on improving the work.

## Expected Behavior

- Be respectful and constructive in issues, pull requests, reviews, and discussions.
- Give feedback about the work, not personal attacks against the person.
- Explain trade-offs clearly when suggesting changes.
- Be patient with contributors who are learning a database engine, framework, or workflow.
- Keep examples safe by avoiding real credentials, production secrets, private customer data, or sensitive internal information.
- Credit useful ideas, scripts, references, or external sources when appropriate.

## Unacceptable Behavior

- Harassment, insults, intimidation, or repeated hostile comments.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Sharing passwords, tokens, private keys, production connection strings, or confidential data.
- Spam, unrelated promotion, or deliberately disruptive activity.
- Misrepresenting unsafe SQL, destructive scripts, or unreviewed automation as production-ready.

## Reporting Issues

If you see behavior that violates this Code of Conduct, report it to the repository maintainers through the available GitHub contact path, issue tracker, or private channel configured for this project.

Do not include secrets, private data, or sensitive screenshots in public reports. If the issue involves security-sensitive information, follow the process in [SECURITY.md](SECURITY.md).

## Enforcement

Maintainers may take action to protect the project and its contributors. Actions can include asking for edits, hiding or removing comments, closing issues or pull requests, limiting participation, or escalating through the hosting platform when necessary.

The goal of enforcement is to keep the project collaborative, safe, and technically useful.
