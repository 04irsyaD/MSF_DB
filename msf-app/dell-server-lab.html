Lab Interaktif: Dell PowerEdge Server

Belajar dari dasar: kenali servernya, bagian-bagiannya, tombol saat boot, iDRAC, RAID, lalu hal yang wajib diperhatikan.

Apa itu Dell PowerEdge?

PowerEdge adalah lini server Dell. Bentuknya mirip PC, tapi dibuat untuk menyala 24 jam, punya komponen cadangan (redundan), dan bisa dikelola dari jauh lewat iDRAC. Di data center, server inilah yang menjalankan OS, hypervisor (mis. VMware ESXi) dan aplikasi.

Rack (R)

Dipasang di rak data center. Tingginya diukur dalam U (1U ≈ 4,45 cm). Paling sering kamu temui.

Tower (T)

Berdiri seperti PC besar. Biasanya di kantor cabang atau ruangan kecil.

Modular (MX)

Banyak server tipis (sled) dalam satu chassis, berbagi power dan jaringan.

Coba: baca nama model

Ketik model seperti R760, R650, T550 atau R7525.

Ini hanya patokan umum. Yang pasti selalu: Service Tag di server, untuk cek spesifikasi dan garansi.

Analogi untuk programmer: server = mesin production tempat aplikasi di-deploy. iDRAC = "remote console + monitoring" bawaan mesin itu, tetap hidup walau OS crash.

Bagian-bagian server

Klik bagian di gambar (atau pilih dari daftar) untuk melihat fungsinya, cara pakai, dan yang perlu diperhatikan. Gambar ini ilustrasi umum 2U, bukan model tertentu.

Tombol (key) saat boot

Saat server menyala, ada beberapa detik di layar awal (POST) untuk menekan tombol khusus. Klik Nyalakan, lalu tekan salah satu tombol sebelum bar penuh.

Di keyboard juga bisa (F11/F12 kadang dipakai browser, jadi klik tombolnya saja).

    Yang wajib diperhatikan

    Aturan yang paling sering menyelamatkan dari outage saat pegang server.

    Lakukan

    • Cek iDRAC Dashboard dan log sebelum menyimpulkan apa pun.
    • Blink komponen dan cocokkan nomor bay/slot sebelum mencabut.
    • Catat Service Tag, waktu kejadian, dan kumpulkan TSR saat buka tiket ke Dell.
    • Pastikan RAID selesai rebuild sebelum pekerjaan lain di server yang sama.
    • Update firmware dan reboot hanya di maintenance window dengan MOP.
    • Pakai ESD strap saat menyentuh komponen di dalam server.

    Jangan

    • Mencabut disk "kira-kira" tanpa Blink, apalagi di RAID yang sudah degraded.
    • Menahan tombol power (force off) server production tanpa izin.
    • Mencabut kedua PSU atau kabel di jalur listrik yang salah.
    • Mengubah BIOS, boot mode, atau RAID tanpa MOP.
    • Membiarkan PSU atau disk rusak "karena server masih nyala": redundansinya sudah hilang.
    • Menyimpan password iDRAC di catatan atau chat biasa.
