## Ringkasan

- **Batch 2 — SSRF koneksi DB (T-023, Critical, OWASP A10/A01)**:
  - Modul baru `db_url_guard.py`: whitelist driver per engine (`postgresql+psycopg2`, `mysql+pymysql`, `sqlite`), whitelist query param (`sslmode`, `charset`, `connect_timeout`), tolak host yang resolve ke IP non-publik (`ip.is_global` + multicast, termasuk IPv4-mapped IPv6, `169.254.169.254`, CGNAT `100.64/10`), tolak unix socket / multi-host.
  - Anti DNS-rebinding: koneksi dikunci ke IP hasil resolve (Postgres via `hostaddr`, MySQL via host = IP). Terverifikasi: psycopg2 konek ke `hostaddr`, bukan resolve ulang.

  - `/health` menambah `features.sqlite_connection`; frontend `DbConnector.tsx` menyembunyikan opsi SQLite jika `false`.
